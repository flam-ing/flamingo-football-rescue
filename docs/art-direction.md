# 원작 관찰 → 독립 게임 화면

## 실제 관찰한 참고

2026-09-07, [와플래시 「유상철, 히딩크를 구해줘」](https://vidkidz.tistory.com/1382)의 조작 화면 및 게임 화면을 확인했습니다. 아카이브는 제작자를 너구리알로 표시합니다. 관찰용 캡처는 이 공개 프로젝트에 포함하지 않습니다.

- 경기장은 큰 회색·흰색 지붕과 빨간 관중석이 화면 대부분을 차지합니다. 작은 선수들은 맨 아래 잔디 위에서 움직입니다.
- 왼쪽 위에 초상과 ENERGY/점수, 오른쪽 위에는 남은 적이 표시됩니다.
- 캐릭터가 좌우로 직접 달립니다. 달리는 중 마우스 클릭은 어깨 태클이며, 낮게 태클하는 상대는 점프해서 밟아야 합니다.
- 큰 머리와 짧은 팔다리의 움직임이 우스꽝스럽습니다. 과장된 킥·태클·전도 자세가 식별됩니다.

## 이 프로젝트가 선택한 것

`unslop-ui`의 특정 참고·색·서체·화면 목적을 먼저 정하는 절차에 따라, 포털이나 카드형 대시보드가 아니라 게임 화면부터 설계했습니다.

- 빨강: 원작의 붉은 유니폼과 관중석을 받는 진홍 유니폼. 노랑: 낮은 태클 경고 및 동료 호출 준비. 파랑: 경기장 하늘과 작전 표시. 보라색 네온이나 범용 UI 테마는 사용하지 않습니다.
- Galmuri11: 한글 플래시 게임 특유의 또렷한 작은 비트맵 문자 분위기를 살리는 로컬 폰트. 한글과 숫자를 동일한 HUD에서 읽도록 구성했습니다.
- 독립 Canvas2D 스크롤 경기장: 지붕·관중석은 느리게, 잔디 선과 캐릭터는 월드 좌표로 이동합니다.
- 타이틀의 큰 플라밍고는 장식용 대표 그림에 그치지 않습니다. 같은 선수의 18동작 아틀라스를 실제 경기의 달리기·킥·태클·공중 헤딩·피격에 사용합니다.
- 흰 오리는 낮게 미끄러지는 태클, 까마귀 골키퍼는 준비 동작 뒤 축구공 투척으로 역할을 구분했습니다. 대장은 단순 체력바만 있는 원형 토큰이 아니라 큰 골키퍼 스프라이트와 빠른 투척 주기를 갖습니다.

## 의도적으로 새로 만든 규칙

원작의 정확한 전체 스테이지 구조를 복원했다고 주장하지 않습니다. 골문 개방 → 동료 2명 구출 → 대장 격파와 감독 구출의 3단계, 응원 기반 동료 호출, 공중 헤딩, 슛으로 적의 공 되받아치기는 이 패러디의 새 규칙입니다.

원작 인물의 얼굴·이름·목소리·로고와 원작 음악은 런타임에 사용하지 않습니다. 모든 선수·적·감독은 새로운 새 캐릭터입니다.
