# 실제 브라우저 검수

2026-09-07 · macOS Codex 내장 Chromium · 1280×720 · 로컬 Vite 4208.

- 타이틀의 구출 작전 시작 → 전반전 브리핑 → 경기장으로 진입했다.
- 실제 짧은 X, Space, Z 입력으로 공 발사, 공중 도약, 공격 포즈를 확인했다. 이후 점수 60, 응원 7, 에너지 57로 전투 상태가 변했다. C는 응원 부족 상태여서 동료 호출 성공으로 기록하지 않는다.
- P 입력 시 시간과 전투가 일시정지되고 작전 타임 메뉴가 열렸다.
- 처음부터 다시 → 브리핑으로 돌아가 에너지 100, 점수/응원 0, 남은 적 8, 160초로 초기화된 것을 확인했다.
- 새 경기에서 다시 X/Space/Z를 눌러 `preview.jpg`를 캡처했다. 실제 UI 조작이며 게임 상태 주입이나 CPU 렌더 이미지가 아니다.
- 경기장 지붕·관중석·원화 선수/적, 상단 에너지·남은 적·시간과 하단 조작 안내가 함께 보인다. 검수 동안 브라우저 warning/error 로그 0건.

최신 23개 엔진 테스트와 기본/컵 난이도 3단계 일반 입력 완주는 별도 자동 검사다. 추가된 입력 큐 회귀 5개는 타격 정지·미처리 스텝의 입력 보존과 수명주기 초기화를 CPU에서 확인하며, 위 브라우저 점검이 이 회귀 경로까지 확인했다는 뜻은 아니다. 사람의 실제 전체 캠페인 완주, 모바일 실기기, 긴 키 누름 이동과 오디오 출력은 이 브라우저 점검에 포함하지 않았다. CPU 미리보기 `previews/cpu-gameplay.png`는 개발 자료로 유지한다.
